## ADDED Requirements

### Requirement: 长按自由复制的文本完整性
用户长按系统选择复制结果记录时：复制按钮文字 MUST NOT 被选入复制内容（按钮区域不可选中）；同一行内的字段之间 SHALL 以 TAB 分隔（粘贴到表格类应用自动分列）；行与行之间 SHALL 保持换行（每条记录一行）。

#### Scenario: 按钮文字不混入
- **WHEN** 用户长按拖动选择光标跨多条记录（含复制按钮区域）后复制
- **THEN** 粘贴内容不含「复制」按钮文字，仅含记录字段文本

#### Scenario: 行内字段 TAB 分隔不换行
- **WHEN** 用户长按自由复制一条记录后粘贴到外部笔记
- **THEN** 该行呈现为「名称→TAB←条形码→TAB←货架号→TAB←价格」单行格式（字段间 TAB 分隔，无行内换行）

#### Scenario: 行间保持换行
- **WHEN** 用户跨 N 条记录选择复制后粘贴到外部笔记
- **THEN** 粘贴内容为 N 行文本，每条记录独立一行

### Requirement: 复制当前列表
结果区 SHALL 提供「复制当前列表」操作，点击后将当前展示的全部行（浏览模式=当前门店全部记录，搜索模式=当前搜索结果）复制到剪贴板：每行字段间以 TAB 分隔，行间以换行分隔，并给予成功反馈。

#### Scenario: 复制搜索结果列表
- **WHEN** 搜索「倍力乐」得到 2 条结果后点击「复制当前列表」
- **THEN** 剪贴板为 2 行文本，每行「名称→TAB←条形码→TAB←货架号→TAB←价格」，成功提示含行数

#### Scenario: 复制浏览模式全部记录
- **WHEN** 浏览模式展示当前门店 101 条记录时点击「复制当前列表」
- **THEN** 剪贴板为 101 行文本，每行字段 TAB 分隔

#### Scenario: 空列表不可复制
- **WHEN** 当前无任何展示行（空门店或无匹配结果）
- **THEN** 「复制当前列表」入口禁用或隐藏，不产生空复制
