## ADDED Requirements

### Requirement: 勾选复制
结果区每行 SHALL 提供勾选框；列表底部 SHALL 固定一条操作栏（左侧全选框 + 右侧主复制按钮），主按钮语义随勾选态切换：未勾选任何行时为「复制当前列表」（复制当前展示的全部行），勾选后为「复制选中（N）」（复制勾选行）；复制内容每行字段间 TAB 分隔，行间换行分隔，并给予成功反馈。此能力替代长按自由复制作为精确格式复制路径（安卓 WebView 跨块选择序列化强制按块换行，无法保证行内格式，实现期实证）。

#### Scenario: 勾选并复制
- **WHEN** 用户勾选 2 条记录后点击「复制选中（2）」
- **THEN** 剪贴板为 2 行文本，每行「名称→TAB←条形码→TAB←货架号→TAB←价格」，成功提示含行数，勾选清空

#### Scenario: 未勾选时复制当前列表
- **WHEN** 未勾选任何行，用户点击「复制当前列表」
- **THEN** 复制当前展示全部行（浏览=当前门店全部，搜索=当前结果），行为与原「复制当前列表」一致

#### Scenario: 全选联动
- **WHEN** 用户点击底部全选框
- **THEN** 全部行进入/退出勾选态，主按钮切换为「复制选中（N）」/「复制当前列表」

#### Scenario: 取消勾选联动
- **WHEN** 用户取消某行勾选后选中计数实时减少；全部取消后按钮回到「复制当前列表」
- **THEN** 复制内容与当前勾选集合一致

#### Scenario: 搜索/浏览模式通用
- **WHEN** 用户在搜索结果或浏览模式列表中勾选记录
- **THEN** 勾选与复制行为一致，切换门店或关键词变更清空勾选集合

### Requirement: 复制当前列表
结果区 SHALL 提供「复制当前列表」操作，点击后将当前展示的全部行（浏览模式=当前门店全部记录，搜索模式=当前搜索结果）复制到剪贴板：每行字段间以 TAB 分隔，行间以换行分隔，并给予成功反馈。

#### Scenario: 复制搜索结果列表
- **WHEN** 搜索「倍力乐」得到 2 条结果后点击「复制当前列表」
- **THEN** 剪贴板为 2 行文本，每行「名称→TAB←条形码→TAB←货架号→TAB←价格」，成功提示含行数

#### Scenario: 复制浏览模式全部记录
- **WHEN** 浏览模式展示当前门店 101 条记录时点击「复制当前列表」
- **THEN** 剪贴板为 101 行文本，每行字段 TAB 分隔

#### Scenario: 空列表不可复制
- **WHEN** 当前无任何展示行（空门店或无匹配结果）
- **THEN** 「复制当前列表」入口禁用或隐藏，不产生空复制
