## REMOVED Requirements

### Requirement: 文件库列表展示
**Reason**: 文件库页整体移除——真机使用反馈导入后仍需再点一次文件才能看数据，属多余中转；导入/冷启动改为直接进入数据列表页（见 excel-import delta）。
**Migration**: 启动与导入路径由「文件库列表 → 点击文件」改为「直达最近导入文件 / 导入完成即达」；空库引导由无文件空态页承接。

### Requirement: 进入工作簿
**Reason**: 「进入工作簿」的触发入口（文件库文件项点击）随文件库页一并移除。
**Migration**: 进入动作由系统自动完成——导入成功直达该文件工作簿页；冷启动直达最近导入文件的工作簿页。

### Requirement: 滑动删除交互
**Reason**: 删除入口只存在于文件库文件项的左滑手势，随文件库页移除；当前最小闭环内不为删除另设入口。
**Migration**: 无替代入口（超出本变更范围）。本地已导入数据仍保留在存储中不清理；同名同大小文件重新导入会自动覆盖更新旧记录。

### Requirement: 逐文件删除
**Reason**: 同「滑动删除交互」——确认删除的调用链（左滑 → 按钮 → 确认框）随文件库页移除。
**Migration**: 无替代 UI 入口；如后续存储清理成为真实需求，以新变更补设计（可在数据列表页顶栏扩展管理入口）。
