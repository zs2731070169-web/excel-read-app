## MODIFIED Requirements

### Requirement: WebView 选择可用性
应用 MUST 保证在安卓 WebView 运行环境中结果区文本可被长按选择（user-select 可用），MUST NOT 被组件库或全局样式禁用选择行为。长按自由选择为应用的唯一复制路径，其行内格式（字段分隔、跨行换行）SHALL 视为尽力而为——安卓 WebView 的选择序列化行为不受应用控制（实现期多轮实证）；应用不提供程序化拼接的精确格式复制路径（底部复制操作栏已随本变更移除）。

#### Scenario: WebView 内长按有效
- **WHEN** 应用以 APK 形式运行在安卓手机上，用户长按结果文本
- **THEN** 系统文本选择菜单正常唤起，复制功能可用（格式尽力而为）

#### Scenario: 格式保真由勾选复制承接
- **WHEN** 用户需要复制结果内容
- **THEN** 长按选择目标范围后经系统菜单复制，行内 TAB 分隔以尽力而为方式保留（应用无程序化拼接路径，如需精确格式保证以新变更评估恢复）

## REMOVED Requirements

### Requirement: 勾选复制
**Reason**: 搜索 → 勾选 → 复制三步路径冗余，真机使用反馈勾选是多余摩擦；勾选集合的状态同步（切门店/关键词变更清空）也增加复杂度。
**Migration**: 复制仅保留长按自由选择（格式尽力而为）。程序化精确格式复制路径（勾选复制及其后继的「一键复制当前列表」方案）均已移除，如需恢复以新变更评估；TAB 分隔定稿结论保留在归档 spec 与 git 历史中可回溯。
